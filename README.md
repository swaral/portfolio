# Swaral Gaur — Portfolio

React + Vite + Framer Motion. The page starts dim; pull (drag or click) the chain under the rattan lamp to switch the light on and reveal the site.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text (about, education, experience, projects, skills, achievements, links) lives in `src/data.js`.
Your resume PDF is `public/Swaral_Gaur_Resume.pdf`; replace it to update the Resume button.

## Deploy

```bash
npm run build
```

Upload the `dist/` folder to Netlify or Vercel (build command `npm run build`, output folder `dist`).
